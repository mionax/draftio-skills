# 小红书竖版封面

小红书封面 = 3:4 竖图 + 一句在信息流里能被读到的标题字。封面在手机上会被压到很小，所以「大主体 + 少字 + 强对比」比精致更重要。

## 何时用

用户这样说时用：

- 「帮我做张小红书封面」「做张封面」
- 「竖版图」「3:4 的图」「封面图」
- 「带标题字」「图上要有大字标题」
- 「笔记首图」「这篇笔记的封面」
- 「封面太丑了，重做一张」

不该用：

- 要横版头图、公众号首图、Banner（16:9 之类）——阅读距离和裁切逻辑都不同，走通用 `draftio-image`。
- 只要纯插画/素材，不需要文字排版。
- 要动图或视频封面——不在本 skill 范围。

## 选型

**默认走二段式，不要一步到位：**

1. **草稿**：`z-image-turbo`，9 点/张（≈¥0.09），一次 4 张共 36 点 ≈ ¥0.36。只判断构图、主体位置、情绪、留白，不看字。
2. **终稿**：方向定了以后用 `seedream-v5-5`，默认 2k 档 58 点（≈¥0.58），1k 档 33 点。

为什么值得多这一步：封面的真实成本是**改稿轮次**，不是点数。直接上终稿模型改五轮，每轮 58 点就是 290 点，还要每次重新描述一遍；4 张草图只要 36 点，先把「主体在哪、字放哪、什么情绪」定死，终稿通常 1–2 轮就过。三毛多买一次确定性，划算。

| 场景 | 模型 id | 点数 | 为什么 |
|---|---|---|---|
| 试构图、试情绪（草稿） | `z-image-turbo` | 9（1k 档） | 最便宜，4 张才 36 点；只定方向，不指望字准 |
| 终稿，中文标题字 | `seedream-v5-5` | 起 33（1k）/ 默认 58（2k） | 中文文字最稳，支持改图，字歪了能在原图上改 |
| 终稿想更省 | `qwen-image` | 35（1k 档） | 支持改图，中文可用，排版精度略低于 Seedream |
| 有参考图，沿用画面只改字 | `seedream-v4-5-edit` | 45（2k/4k 档） | 支持改图，适合在原图上换标题、换主体 |
| 中文标题 + 要 4k 交付 | `seedream-v5-lite` | 61（2k/4k 档） | 支持改图，能上 4k，适合印刷或大屏 |
| 英文标题、信息密集 | `gpt-image-2` | 起 60 / 默认 80（2k） | 英文结构化排版强，多行小字更整齐 |
| 只要氛围底图、艺术感 | `midjourney` | 173（一次 4 张） | 风格化最强，但不支持改图、不控字，只能当底图 |

## 提示词配方

骨架（Seedream / Qwen 方言，中文直写）：

```
3:4 竖版小红书封面。主体：{主体}，{主体状态或动作}，位于画面{位置}，占画面约{占比}。背景：{背景与层次}。光线：{光线}，整体情绪{情绪}。{留白位置}留出干净留白，标题文字写「{标题文字}」，{字体气质}，{颜色}，字要清晰可读。风格：{风格}，高对比，信息流缩略图下仍可辨认。不要水印，不要多余小字。
```

硬规则：

- **画面里要出现的文字必须用中文引号包起来**，写 `标题文字写「手冲入门」`。不括起来，模型会当成描述而不是要渲染的字。
- 标题控制在 **6–12 字**、最多两行。字越多，错字率越高。
- 一次只要求一组字；要副标题就明确写「副标题写「…」」，别让模型自由发挥。
- 留白必须写出来（「上方留白」「左侧留白」），否则主体顶满，后期没地方放字。
- GPT Image / Nano Banana 换成英文结构化句子；Midjourney 用关键词流 + `--ar 3:4`。

填好的例子（Seedream 5.5，2k 档 58 点）：

```
3:4 竖版小红书封面。主体：一杯手冲咖啡，琥珀色液体，杯口有薄薄热气，位于画面中下部，占画面约 45%。背景：浅米色亚麻桌布，左上角一截虚化的绿植，层次干净。光线：清晨侧逆光，柔和暖调，整体情绪安静、治愈。画面上方留出整片干净留白，标题文字写「手冲入门」，思源黑体加粗，深棕色，字要清晰可读。副标题写「3 个新手常犯的错」，字号约为标题一半。风格：日系生活摄影，高对比，信息流缩略图下仍可辨认。不要水印，不要多余小字。
```

英文写法（GPT Image 2）：

```
vertical 3:4 social cover, a pour-over coffee cup on linen, soft morning backlight, large clean empty space at the top, bold sans-serif headline "手冲入门", subtitle "3 个新手常犯的错", high contrast, no watermark
```

## 参数

- **比例固定 3:4**。小红书封面用这个比例最不容易被信息流二次裁切。
- **草稿**：`z-image-turbo` 只有 1k 档，9 点/张，一次 4 张（36 点）。
- **终稿**：`seedream-v5-5` 选 **2k 档 58 点**（默认档）。1k 档 33 点只用来「先看字对不对」，不要拿它交付，手机上标题会发虚。
- **张数**：草稿 4 张，终稿 1–2 张。终稿要 2 张时只改一句（换标题或换主体），不要全改。
- 需要 4k 交付（印刷、大屏）才换 `seedream-v5-lite`（61 点）或 `minimax-h3-image`（52 点）。
- 报价写「点数 + 约合人民币」：1 点 ≈ ¥0.01；注册送 500 点，30 天有效。

## 验收清单

把图缩到手机信息流大小（约 200px 宽）再看，逐条过：

- [ ] 缩略图下标题仍能读清：至少 3 个字认得出来，没有错字、缺笔、糊成一团。
- [ ] 主体没被裁：头顶、杯口、产品边缘都在画面内，没有被 3:4 边界切掉。
- [ ] 留白够放字：标题区没和主体、高光打架；字压在杂乱背景上就要重做。
- [ ] 一张图只讲一件事：第一眼能说出「这是什么」，不需要看图注。
- [ ] 文字没有自己长出来：除指定的标题和副标题，没有乱加的小字、水印、英文。
- [ ] 风格统一：主色不超过 3 个，和账号已有封面放一起不违和。

## 返工路径

| 典型失败 | 改哪一句 | 换哪个模型 |
|---|---|---|
| 标题缺笔 / 错字 / 糊 | 标题缩到 6 字以内，补一句「字要清晰可读，笔画完整」 | 仍错就用 `seedream-v4-5-edit`（45 点）在原图上重排文字 |
| 主体顶满、没地方放字 | 把「占画面约 45%」改小到 35%，并明写「上方留出整片干净留白」 | 不用换，仍用 `seedream-v5-5` |
| 构图对了但氛围不对 | 只改「光线 + 情绪」两句，别动主体和留白描述 | 保持 `seedream-v5-5`；要更强风格化再上 `midjourney`（173 点/4 张，仅作底图） |
