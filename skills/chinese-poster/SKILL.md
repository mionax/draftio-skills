# Chinese Poster（中文海报）

> 装了 Draftio MCP 就直接出图（`estimate` → `generate_image` → `get_generation`）；没装就只给选型、提示词和报价，出图交给画布。

## 何时用我

分水岭只有一个：**「字」是不是交付物的一部分**。

用我：

- 海报、活动主视觉、门店 KT 板、易拉宝
- 小红书封面、公众号首图里要压中文标题
- 菜单、价签、包装正面、礼盒、吊牌
- 用户原话：「帮我做张中文海报」「图上要有这几个字」「标题写…」「菜单设计」

别用我（转交）：

- 文字主体是英文，或重点是信息结构而非中文字形 → [`text-layout`](../text-layout/SKILL.md)
- 用户已经有图，只想去背 / 擦除 / 放大 / 换背景 → [`image-editing`](../image-editing/SKILL.md)
- 图上一个字都不要，字只是氛围元素 → [`draftio-image`](../draftio-image/SKILL.md)

## 选型

| 情况 | 用什么 | 为什么 |
|---|---|---|
| 默认，主标题 ≤ 12 字 | `seedream-v5-5` | 中文字形最稳，短标题缺笔率最低，改图也支持 |
| 文字组多、层级复杂、要反复改字 | `gpt-image-2` | 指令理解最强，能守住「这块写什么」 |
| 已有海报只换标题 | `gpt-image-2.5-flare` | 局部改，保住原版式和配色 |
| 只定构图、字先不管 | `z-image-turbo` | 最便宜，但别指望它写字 |

判断顺序：

1. 字少（≤ 12 字）、要便宜 → `seedream-v5-5`。
2. 字多 / 有副标题 + 角标 / 版式复杂 → 直接 `gpt-image-2`，省下的返工比差价贵。
3. 用户已经有一张满意但字不对的图 → 不要重新生成，走 `gpt-image-2.5-flare` 改字。
4. **不要用 Midjourney 写中文**：它不吃文本指令，必出乱码。

## 提示词配方

顺序固定，五段：**用途与画幅 → 画面 → 文字区 → 层级 → 反面清单**。

1. 用途与画幅先写（`3:4 竖版活动海报`），模型据此决定留白。
2. 画面写主体、场景、光线、风格，不写「高级」「大气」这种空词。
3. **文字区单独成段**，要出现的字一律用「」括起来——不括，模型只当描述读，不渲染。
4. 层级写「谁最大、在哪、什么颜色、什么字体类别、占多高」。
5. 反面清单固定收尾：`不要乱码汉字、不要多余小字、不要水印和二维码`。

层级写法（中文海报最容易崩的地方）：

```
文字区：主标题「秋日限定」，超粗中文黑体，深棕字加白描边，位于画面上三分之一，占画幅高度约 28%；
副标题「9.20–10.20 限时上新」，字号约主标题一半，居中排在主标题下方；
角标「门店自提」，右下角，约主标题四分之一大小。
```

三条硬规则：

- **文字组数 ≤ 3**：主标题 + 副标题 + 一组角标就是上限，第 4 组几乎必糊。
- **主标题 ≤ 12 字、最多两行**；四字短语最稳，英文数字混排要单独说明。
- **留白写死位置和比例**（`上方 35% 为整片留白`），否则主体顶满，字只能压在人脸上。

## 参数

- 比例跟投放位走：小红书 3:4、公众号首图 16:9 或 2.35:1、门店海报 3:4、菜单/包装按实际开面单独定。
- 分辨率：**带字的图一律 2k 档起**。1k 只能验构图，字在 1k 下不可判。
- 报价：先 `estimate`；没 MCP 就查 `https://www.draftio.cn/api/v2/public/models`。报**起价 + 所选定档位**两个数，不背价格、不和厂商官价比。
- 先出 1 张验字，字对了再批量；不要同一句提示词一次跑 4 张。
- 编辑类（改字）要说明「保留第几张图的什么」，参考图顺序就是画布顺序。

## 验收清单

缩到 200px 宽看，**能读出来才算过**：

- [ ] 每个字都认得出：没有缺笔、粘连、错字、简繁混用。
- [ ] 只有我要求的那几组字，没有模型自加的英文、数字、假 logo。
- [ ] 层级成立：主标题一眼最大，副标题明显次之，互不打架。
- [ ] 字没压主体关键部位（人脸、产品、按钮、价格）。
- [ ] 颜色 ≤ 3 个，和品牌主色不冲突。
- [ ] 留白区干净，后期若要叠字还有位置。

## 返工路径

| 失败 | 先改哪一句 | 还不行 |
|---|---|---|
| 字糊 / 缺笔 | 主标题压到 8 字内，补「笔画完整、字要清晰可读」 | 换 `gpt-image-2` 重出 |
| 错字 / 乱码 / 冒英文 | 加「只出现这几组字，不要其它文字」，并逐字列出 | 换模型；仍错就走下面「不信模型写字」 |
| 字挤在一起 | 写明每组字的纵向位置与字号比例 | 减掉一组字 |
| 主体太满没处放字 | 补「上方 35% 留白」，同时调小主体占比 | 换 `seedream-v5-5`，画面更收 |
| 版式满意但字要换 | 保持提示词不动，用 `gpt-image-2.5-flare` 只改文字层 | — |
| 风格偏了 | 删形容词，改成具体材质/光线/参考物 | 回入口 skill 换风格族模型 |

**不信模型写字**：菜单价格、法律声明、必须逐字准确的文案，不要交给模型渲染。让它出**留白版**画面，字在编辑器里叠——零错字率，且随时可改。这是本 skill 最重要的一条判断。

出图入口：https://www.draftio.cn/canvas 。
