# Image Editing（改图工具箱）

> 装了 Draftio MCP 就直接出图（`estimate` → `generate_image` → `get_generation`）；没装就只给方案与顺序，操作在画布上完成。

## 硬规则：先确认「图在哪」

**用户必须已经有一张图。** 没有图就不是改图任务，是生成任务——转回 [`draftio-image`](../draftio-image/SKILL.md)，不要在这里推荐工具。

确认三件事，缺哪件问哪件：

1. **图在哪**：本地文件 / 已有公开链接 / 图在聊天里。
2. **改哪一块**：整个人、某个物体、背景、还是全图。
3. **改完要什么**：透明底 PNG、干净背景、更高分辨率、另一个视角。

**图片输入一律是可访问的 URL**：本地文件先在 https://www.draftio.cn/canvas 上传拿到链接；不要把本地路径当 URL 传，也不要承诺帮用户上传。

## 何时用我

| 用户说 | 去哪 |
|---|---|
| 去掉背景、抠图、要透明底 | `image-background-remover` |
| 把路人 / 水印 / logo / 电线擦掉 | `image-eraser` |
| 放大、变清晰、修复糊图 | `real-esrgan` |
| 多角度、换机位、转个方向 | `qwen-image-multiple-angles` |
| 换背景、换衣服、改材质 | 不属于这四件套 → 生成式编辑（`gpt-image-2.5-flare` / `seedream-v4-5-edit`） |

区分标准：**目标是否确定且唯一**。去背、擦除、放大、转视角都只有一个正确答案，用工具；换背景、换风格有无数种答案，用生成模型。

## 四个工具的现实边界

- **`image-background-remover` 只去背景，不换背景。** 想要新背景 = 先去背拿透明 PNG → 再走生成式编辑把主体合成到新场景。两步，别指望一次调用。
- **`image-eraser` 需要标出要擦的位置。** 画布上涂蒙版（白区擦除、黑区保留）最准；只靠文字描述时模型要猜，边缘容易留残影。复杂物体带投影时，先擦主体再补一次地面纹理，比一次擦干净更稳。
- **`real-esrgan` 只提升分辨率，不增加细节语义。** 糊到没信息的图放大后只是更大的糊；文字被压缩坏掉的图，放大不会把字修回来。倍数不由提示词控制，产物尺寸以接口返回为准。
- **`qwen-image-multiple-angles` 适合「有明确主体」的图**（人、产品、手办、房间一角），并且**必须写清角度**：`turn 45 degrees to the left`、`front view`、`top-down`。没有主体（风景、抽象图）转视角只会得到另一张无关的图。
- 需要精确蒙版（复杂轮廓、多人）时，可先用 `sam3-image` 生成蒙版，再交给 `image-eraser` 或合成流程；这是「先分割、再动手」的顺序。

## 顺序（决定成败）

1. **先看原图质量**：分辨率低到主体边缘都糊 → 先放大再抠图没用，应该先换源图。
2. **去背永远排在最前**：任何换背景、合成、加投影都以透明 PNG 为输入。
3. **放大与擦除的顺序看原图**：原图偏小、非放大不可 → 先放大再擦，擦除才有足够像素可用；原图已够清晰 → 先擦再放大，免得把噪点和压缩痕迹一起放大。
4. **多角度在最后**：它是「再造一张图」，前面对原图做的任何修饰都可能不被保留。
5. **一次只做一个动作**，串起来做，每步验收后再走下一步。

## 提示词与参数

- 这四个工具**不吃风格词**。不要写「高级感」「电影感」，写了也不会生效，只会让用户误以为有更多可调项。
- `image-eraser` 的文字描述写**位置 + 物体**：`remove the person standing on the left edge, keep the wall and shadow pattern`。
- `qwen-image-multiple-angles` 的 prompt 只写**角度与保留项**：`three-quarter view from the front-left, keep the same product shape, color and label`。
- 去背与放大没有比例参数，输出比例跟原图走；多角度可能改画幅，提前告诉用户。
- 报价：先 `estimate`（无 MCP 查 `https://www.draftio.cn/api/v2/public/models`），报单价 × 次数；多步流程要把每一步加起来，不要只报第一步。
- 输出格式：要透明底必须拿 PNG；JPEG 会把透明区填成白或黑。
- **批量前先跑一张**：同一套操作要作用在 20 张图上时，先在 1 张上验收；边缘/纹理类失败会按张数等比复制，越早发现越省。

## 验收清单

- [ ] **去背**：主体边缘没有白边/绿边/灰边；发丝、半透明处没有硬切；角落背景真透明（不是伪白底）。
- [ ] **擦除**：擦除区域纹理连续，没有模糊补丁、重复图案、颜色断层；原物体没有残留一角。
- [ ] **放大**：放大后没有塑料感、过锐光晕、油画涂抹；文字边缘仍可读（原本可读的前提下）。
- [ ] **多角度**：主体身份一致（同一张脸、同一个产品、同一套配色），没有被重新设计。
- [ ] **通用**：尺寸与比例符合用途；关键部位没有被裁；没有新增水印。

## 返工路径

| 失败 | 先改什么 | 再不行 |
|---|---|---|
| 去背后边缘有白边 | 换 PNG 输出，别用 JPEG；缩小蒙版 1–2px | 在原图上先轻微提亮边缘再抠 |
| 去背后发丝丢失 | 这张图不适合自动去背，转生成式编辑重绘主体 | 换更清晰的源图 |
| 擦除留残影 / 糊块 | 缩小蒙版范围，只框住物体本体；描述里写清「保留地面纹理」 | 先 `sam3-image` 出精确蒙版再擦 |
| 擦完出现重复纹理 | 改成分块擦，两次少量而不是一次大块 | 用生成式编辑修补该区域 |
| 放大后更糊 / 更假 | 确认源图本身有细节；没有就换图 | 只放大到 2x 用途够用即停 |
| 多角度换了个人 / 换了产品 | prompt 里逐项写「保持…不变」，并挂 2–3 张参考图 | 这个主体不适合多角度，回到生成式编辑 |
| 换背景效果假 | 检查是不是两步：去背 → 合成；并统一新场景的光向与色温 | 换 `gpt-image-2.5-flare` 重做合成 |

出图入口：https://www.draftio.cn/canvas 。本 skill 只写判断与顺序；工具清单与价格以 `list_models` / 接口返回为准。
