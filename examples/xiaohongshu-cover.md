# 小红书爆款封面


> 这是 [draftio.cn/prompt-library/70da5c2a](https://www.draftio.cn/prompt-library/70da5c2a) 那份配方的离线版。
> 想看带成品图的效果、或者直接出图，去站点上那一页；这里只有文字配方。


封面在信息流里只有拇指大小。判据不是「好不好看」，是**缩略图下一眼能不能读出这是什么**：大主体、少字、强对比，精致排在后面。

## 何时用

用户这样说时用：

- 「帮我做张小红书封面」「做张封面」「封面图」
- 「要竖版图」「3:4 的」「笔记首图」
- 「带标题字」「图上要有大字标题」「爆款封面那种」
- 「封面太丑了，重做一张」「标题字要能看清」

不适用：横版头图 / 公众号首图 / Banner（16:9，裁切逻辑不同，走通用 `draftio-image`）；只要纯插画不要文字；视频或动图封面。

想要更多可调参数的同款模板，见 `https://www.draftio.cn/prompt-library`（模板 id 前缀 `70da5c2a`）。

## 先问这三件事

1. **选题是什么**——决定封面类型（教程 / 自拍日常 / 婚礼 / Vlog / 家居 / 摄影 / 运营干货）和博主身份。
2. **有没有人像参考图**——有就必须走 i2i，按第 4 节固定写法；没有就按选题生成一位博主人设。
3. **标题字要不要出现在图上**——进图就用文字生成模型；不进图就留白后期叠字，可控性更高。

信息不全时**只问最关键的那一个**，其余按选题自行补齐（教程→知识博主 + 明亮桌面；家居→生活博主 + 客厅；摄影→摄影博主 + 咖啡馆）。不要连着追问三轮。

## 选型

**首选 `gpt-image-2`**：中文标题排版最准，多行标题、副标题、贴纸字都不容易糊。60 点起 / 默认 2k 80 点。封面是「字必须能读」的活，这一档差价通常比多改两轮便宜。

| 用途 | 模型 | 点数 | 备注 |
|---|---|---|---|
| 终稿（默认） | `gpt-image-2` | 60 / 默认 2k 80 | 文字排版最准，支持改图 |
| 终稿（省一半） | `seedream-v5-5` | 33 / 默认 2k 58 | 中文短标题同样稳，支持改图 |
| 只出草稿定构图 | `z-image-turbo` | 9 | **不支持改图**，只能 t2i |

必须换的信号：

- 有参考人像 → 只能 `gpt-image-2` 或 `seedream-v5-5`（支持 i2i）；`z-image-turbo` 不能碰。
- 标题 ≤6 字、预算敏感 → `seedream-v5-5` 2k 58 点，成片率不比前者低。
- 要 4 张一起挑方向 → 草稿阶段用 `z-image-turbo`，别拿终稿模型试错。

## 提示词配方

六个槽位填满，就是一条能直接用的中文提示词。

```
3:4 竖版小红书封面。主体：{谁/什么}，{动作或状态}，位于画面{位置}，占画面约 {45–70}%，以贴纸式抠图呈现、外圈粗白描边。场景：{日常场景}，背景高亮低杂、浅景深轻微虚化。构图：{标题区位置}留出约 {25–40}% 的整片文字区，主体不压字、不越界。光线：{柔和窗光/自然光}，整体{情绪}。文字区：标题「{4–10 字}」，超粗中文黑体，{配色}，带白描边和轻微倾斜，占画面高度约 30%；副标题「{一句话}」字号约标题一半。风格：{风格}，主色不超过 3 个，高对比，缩略图下仍可辨认。不要水印、logo、二维码，不要多余小字，不要乱码汉字。
```

三条硬规则：

- 图上要出现的字**必须用「」包起来**，否则模型只当描述读，不渲染。
- 标题 **4–10 字**，最多两行；越短错字率越低。副标题只给一组，别让模型自由发挥。
- **留白要写出来**（「左上 30% 整片留白」），否则主体顶满，标题没地方落。

有参考人像时，开头加一句：`保持参考图（图1）人物的脸型、五官比例、发型和整体气质不变，不要换脸，只替换场景、服装、光线和文字区。`

填好的例子（选题：手冲咖啡入门；人设：知识博主）：

```
3:4 竖版小红书封面。主体：一位二十多岁的女性知识博主，白色针织上衣，站在浅木色吧台后，一手举着手冲壶，另一只手指向画面左上角标题区，自信微笑看向镜头，以贴纸式抠图呈现、外圈粗白描边，占画面约 55%。场景：明亮整洁的厨房，背景是虚化的木质置物架和一株绿植，浅景深轻微模糊。构图：人物居中偏右，左上 30% 留出整片文字区，主体不压字、不越界。光线：窗边柔和自然光，主光偏暖，人物轮廓有一圈淡淡高光，整体安静、可信。文字区：标题「手冲入门」，超粗中文黑体，深棕字加白描边、轻微倾斜，占画面高度约 30%；副标题「3 个新手常犯的错」字号约标题一半，装在白色手绘对话框贴纸里。风格：真实摄影 + 轻度海报感，主色只有棕、米白、绿，高对比，缩略图下仍可辨认。不要水印、logo、二维码，不要多余小字，不要乱码汉字。
```

## 参数

- **比例固定 3:4**，平台信息流默认裁切最友好，别用 1:1 或 9:16。
- **分辨率**：终稿走 2k 默认档（`gpt-image-2` 80 点 / `seedream-v5-5` 58 点）；1k 只用来快速验字，不拿来交付。
- **二段式**：草稿 `z-image-turbo` 9 点 × 4 = **36 点**（纯 t2i，别塞参考图）→ 定稿 1 张。
  - `gpt-image-2` 2k：36 + 80 = **116 点 ≈ ¥1.16**
  - `seedream-v5-5` 2k：36 + 58 = **94 点 ≈ ¥0.94**
- 终稿只出 1 张；要对比就只改一句话（换标题或换主体），别整套重写。
- 计价：1000 点 = ¥10；注册送 500 点（30 天有效）。

## 验收清单

把图缩到 200px 宽再逐条过：

- [ ] 标题字可读：认得出全部字，没有缺笔、糊边、串字。
- [ ] 主体没被裁：头顶、手、产品边缘都在 3:4 画幅内。
- [ ] 留白够：标题区没和主体、高光打架，字不压细节。
- [ ] 风格统一：主色 ≤3 个，和账号已有封面放一起不违和。
- [ ] 缩略图下仍清楚：第一眼能说出这是什么，不需要看图注。

## 返工路径

| 典型失败 | 先改哪一句 | 还不行就换 |
|---|---|---|
| 字糊了 / 缺笔 | 标题压到 6 字内，补「笔画完整，字要清晰可读」 | 换 `gpt-image-2` 重出，或原图局部重排 |
| 字乱码 / 冒出英文 | 加「只出现标题和副标题这两组字，不要其它文字」 | 换 `gpt-image-2`；仍乱就把字删掉，后期叠字 |
| 主体太小 / 被裁 | 占比从 45% 提到 60%，加「头顶和手部完整在画内」 | 不用换模型 |
| 太花 / 杂乱 | 删掉装饰元素，写「主色不超过 3 个，背景干净低杂」 | 换 `seedream-v5-5`，画面更收 |
| 缩略图看不清 | 标题占高提到 30–35%，改黑黄或白黑高对比配色 | 换 `gpt-image-2` |
